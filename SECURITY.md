# Política de segurança

## Como relatar uma vulnerabilidade

Encontrou um problema de segurança no dashboard, na API ou no código deste repositório?
**Não abra uma issue pública.** Relate em particular pelo GitHub:

1. Acesse a aba [**Security**](https://github.com/guigofranca/job-market-skill-gap-analyzer/security)
   do repositório.
2. Clique em **Report a vulnerability** e descreva o problema: o que é afetado, como reproduzir e
   qual o impacto.

Só eu e você veremos o relato. Respondo em até 7 dias e aviso quando a correção for publicada.
Se quiser, você é creditado no aviso de segurança.

## Escopo

- O dashboard ([seu-empregobr.vercel.app](https://seu-empregobr.vercel.app)) e a API que o alimenta.
- O código deste repositório, incluindo os workflows do GitHub Actions.

Fora do escopo: os sites de onde as vagas são coletadas (relate a eles diretamente), ataques de
negação de serviço e relatórios gerados só por ferramentas automáticas, sem um impacto demonstrado.

## Versões suportadas

Só a versão em produção, que é sempre a branch `main`.
